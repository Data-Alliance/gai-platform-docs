    gcube란?

    GPU가 필요한 개발자와, 유휴 GPU를 보유한 공급자를 연결하는 GPU 공유 클라우드 플랫폼입니다.

    왜 gcube인가

    AI 모델 학습, 딥러닝 추론, 영상 렌더링에는 고성능 GPU가 필수입니다.
    그러나 기존 퍼블릭 클라우드는 비용 부담이 크고, 유휴 GPU 자원은 곳곳에 방치되어 있습니다.

    gcube는 이 두 가지 문제를 동시에 해결합니다.

    • 소비자 — 기존 GPU 클라우드 대비 최대 90% 비용 절감
    • 공급자 — 사용하지 않는 GPU를 공유해 추가 수익 창출

    gcube로 할 수 있는 것

    워크로드 설명
    AI/ML 학습 딥러닝 모델 학습 및 파인튜닝
    LLM 추론 Ollama, vLLM 등 오픈소스 모델 서빙
    영상 렌더링 GPU 가속 렌더링 파이프라인 실행
    Jupyter 환경 노트북 기반 인터랙티브 연구 환경

    핵심 기술

    이기종 GPU 풀링

    다양한 제조사·모델의 GPU(RTX 3090, H100 등)를 하나의 풀로 통합 관리합니다.
    워크로드에 맞는 GPU를 유연하게 선택할 수 있습니다.

    컨테이너 기반 멀티테넌시

    컨테이너 격리 기술로 여러 사용자가 동일한 GPU를 안전하게 동시 사용할 수 있습니다.
    데이터 보안과 환경 일관성을 모두 보장합니다.

    블록체인 기반 공정 보상

    특허 등록된 분산 기여도 산출 시스템으로 공급자에게 투명하고 공정한 보상을 제공합니다.

    빠르게 시작하기

    • Ollama + API 서빙 — 오픈소스 LLM을 gcube에서 바로 서빙
