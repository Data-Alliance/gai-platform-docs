# **노드 연결하기**

에이전트를 설치하여 내 GPU를 gcube에 연결합니다.

!!! tip
    노드를 연결하면 내 GPU가 gcube 플랫폼에 등록되어 공유가 시작됩니다.

## **시작 전 확인 사항**

- NVIDIA GPU가 설치된 Windows PC 또는 서버가 필요합니다.
- NVIDIA 드라이버가 정상 설치되어 있어야 합니다.
- gcube 계정 로그인 후 Share Mode로 전환된 상태여야 합니다.

## **연결 방법**

1. Share Mode 좌측 메뉴에서 **새 노드 연결**을 클릭합니다.
![001_connect-node](img/connect-node/001_connect-node.png)
2. **Download Program** 버튼을 클릭해 에이전트 프로그램을 다운로드합니다.
![002_connect-node](img/connect-node/002_connect-node.png)
3. 다운로드한 설치 파일을 실행하고 화면의 안내에 따라 설치를 완료합니다.
![003_connect-node](img/connect-node/003_connect-node.png)
4. 설치가 완료되면 자동으로 GPU 공유가 시작됩니다.

!!! warning
    NVIDIA 드라이버가 인식되지 않는 경우 문제 해결 가이드를 참고하세요
