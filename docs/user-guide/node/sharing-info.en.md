# **Check Sharing Info**

Check the specs, status, and earnings of your shared GPU.

!!! tip
    You can view detailed information for each shared GPU device at a glance on the node screen.

## **Available Information**

| **Item** | **Description** |
| --- | --- |
| Node Name & Running Status | Whether the node is currently sharing (running) or stopped |
| GPU Specs | GPU model name, VRAM, and other hardware specs |
| Device Specs | CPU, memory, and other system specs |
| Running Time | Cumulative running time of the current sharing session |
| Earnings Info | Total earnings, base fee, and usage fee |
| Last Updated | Timestamp of the last status update |

## **How to Check Sharing Info**

1. Go to the node list screen from the left menu in Share Mode.
![001_sharing-info](img/sharing-info/001_sharing-info.png)
2. If you have many devices, switch to list view to see a summary at a glance.
![002_sharing-info](img/sharing-info/002_sharing-info.png)

Click a node name to go to that node's detail page.
