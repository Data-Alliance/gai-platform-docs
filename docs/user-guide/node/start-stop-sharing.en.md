# **Start and Stop Sharing**

Pause or restart GPU sharing from the agent.

!!! tip
    GPU sharing is started and stopped directly from the agent program.
    This is done through the agent app installed on your PC, not the console web page.

## **How to Stop Sharing**

1. Run the agent program on your PC.
2. Click Running under the Status section in the center of the agent.
![001_start-stop-sharing](img/start-stop-sharing/001_start-stop-sharing.PNG)
3. Click Stop among the Run and Stop options.
4. Wait briefly after the status changes to Turning off.
![002_start-stop-sharing](img/start-stop-sharing/002_start-stop-sharing.PNG)
5. When Stopped is displayed, sharing has been completely halted.
![003_start-stop-sharing](img/start-stop-sharing/003_start-stop-sharing.PNG)

## **How to Restart Sharing**

1. Click Stopped under the Status section in the agent.
2. Click Run to resume sharing.

!!! warning
    While sharing is stopped, consumers cannot use your GPU and no earnings will be generated.
