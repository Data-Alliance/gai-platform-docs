# **gcube란?**

## **시작하기 전에 알아야 할 핵심 개념**

gcube는 유휴 GPU를 보유한 공급자와, GPU가 필요한 소비자를 연결하는 GPU 공유 클라우드 플랫폼입니다.

---

## **gcube가 해결하는 문제**

AI 개발, 영상 렌더링, 딥러닝 학습에는 고성능 GPU가 필요하지만, 기존 클라우드 서비스는 비용 부담이 큽니다.<br> 
반대로 고성능 GPU를 보유하고 있지만 항상 사용하지 않는 경우도 많습니다.

gcube는 이 두 가지 문제를 동시에 해결합니다.

- **공급자:** 사용하지 않는 GPU를 공유해 추가 수익 창출
- **소비자:** 기존 GPU 클라우드 대비 최대 90% 비용 절감

---

## **gcube의 3가지 핵심 특징**

| **특징** | **설명** |
| --- | --- |
| 이기종 GPU 풀링 | 다양한 제조사·모델의 GPU를 하나의 풀로 통합 관리 |
| 컨테이너 기반 멀티테넌시 | 여러 사용자가 동일 GPU를 안전하게 동시 사용 |
| CES 2026 혁신상 수상 | 글로벌 기술 혁신성 공인 |
