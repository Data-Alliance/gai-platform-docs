    gcube Docs에 오신 것을 환영합니다

    gcube는 유휴 GPU 자원을 클라우드로 연결하는 GPU 공유 플랫폼입니다. 누구나 저렴하게 GPU를 빌리고, 보유한 GPU로 수익을 얻을 수 있습니다.

    콘솔 바로가기 gcube란?

      AI 모델 학습, 추론, 렌더링 등 GPU 작업이 필요한 개발자·연구자

    주요 기능

    기능 설명
    이기종 GPU 풀링 서로 다른 NVIDIA GPU 모델을 하나의 풀로 통합
    컨테이너 기반 멀티테넌시 컨테이너로 완전한 격리 환경 제공
    블록체인 기반 공정 보상 투명한 사용량 측정 및 정산
    gcube CLI 커맨드라인에서 워크로드 관리
