# **워크로드 대시보드**

보유 포인트와 운영 중인 워크로드 현황을 확인합니다.

!!! tip
    워크로드 대시보드는 Workload Mode의 첫 화면입니다. 
    포인트 잔액과 전체 워크로드 현황을 한 곳에서 확인할 수 있습니다.

## **확인할 수 있는 정보**

| **항목** | **설명** |
| --- | --- |
| 보유 포인트 | 현재 사용 가능한 포인트 잔액 |
| 워크로드 전체 현황 | 생성한 워크로드의 요약 운영 상태 |
| 워크로드 상세 | 개별 워크로드 클릭 시 상세 정보 확인 가능 |

## **대시보드 사용 방법**

1. Workload Mode에서 좌측 메뉴의 대시보드를 클릭합니다.
![001_workload-dashboard](img/workload-dashboard/001_workload-dashboard.png)
1. 상단에서 보유 포인트를 확인합니다. 포인트가 부족한 경우 충전이 필요합니다.
![002_workload-dashboard](img/workload-dashboard/002_workload-dashboard.png)
1. 워크로드 목록에서 각 워크로드의 운영 상태를 확인합니다.
![003_workload-dashboard](img/workload-dashboard/003_workload-dashboard.png)

!!! warning
    워크로드가 없는 경우 아직 워크로드를 등록하지 않은 상태입니다. 
    아래 다음 단계를 따라 등록을 시작하세요.
