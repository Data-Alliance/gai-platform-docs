# **공급자 vs 소비자**

gcube에는 두 가지 사용 역할이 있습니다:

!!! tip
    같은 계정으로 두 역할 모두 사용할 수 있습니다. 로그인 후 좌측 메뉴 상단의 모드 변경 버튼으로 전환하세요.

| **구분** | **🖥️ 공급자 (Node)** | **⚡ 소비자 (Workload)** |
| --- | --- | --- |
| 나는? | GPU를 보유하고 있다 | GPU가 필요하다 |
| 목적 | 유휴 GPU로 수익 창출 | AI 모델 실행, 개발 환경 구축 |
| 사용 메뉴 | Share Mode | Workload Mode |
| 필요한 것 | NVIDIA GPU, 에이전트 설치 | 포인트 충전 |
| 다음 단계 | GPU 공유하기 가이드 → | GPU 사용하기 가이드 → |

---

## **모드 전환 방법**

1. gcube 콘솔(console.gcube.ai)에 로그인합니다.
2. 좌측 메뉴 가장 상단의 모드 변경 버튼을 클릭합니다.
3. Share Mode(공급자) 또는 Workload Mode(소비자)를 선택합니다.

!!! warning
    모드를 전환해도 계정 정보와 포인트는 유지됩니다.
