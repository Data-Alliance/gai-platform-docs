# **Provider vs Consumer**

There are two user roles in gcube:

!!! tip
    You can use both roles with the same account. After logging in, switch between modes using the mode toggle button at the top of the left menu.

| **Category** | **🖥️ Provider (Node)** | **⚡ Consumer (Workload)** |
| --- | --- | --- |
| I am... | Someone who owns a GPU | Someone who needs a GPU |
| Purpose | Generate revenue from idle GPU | Run AI models, build dev environments |
| Menu | Share Mode | Workload Mode |
| Requirements | NVIDIA GPU, Agent installation | Point balance |
| Next Step | GPU Sharing Guide → | GPU Usage Guide → |

---

## **How to Switch Modes**

1. Log in to the gcube console (console.gcube.ai).
2. Click the mode toggle button at the very top of the left menu.
3. Select Share Mode (Provider) or Workload Mode (Consumer).

!!! warning
    Switching modes does not affect your account information or point balance.
