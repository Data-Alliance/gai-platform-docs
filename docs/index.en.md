# Welcome to gcube Docs

**gcube** is a GPU sharing cloud platform that connects idle GPU resources.
Anyone can rent GPU at low cost, or earn revenue by sharing their own GPU.

[Go to Console :material-arrow-right:](https://console.gcube.ai/){ .md-button .md-button--primary }
[What is gcube? :material-information-outline:](user-guide/sign-up/what-is-gcube.en.md){ .md-button }

## Key Features

| Feature | Description |
|---|---|
| Heterogeneous GPU Pooling | Unifies different NVIDIA GPU models into a single pool |
| Container-based Multi-tenancy | Provides fully isolated environments via containers |
| Blockchain-based Fair Reward | Transparent usage tracking and settlement |
| gcube CLI | Manage workloads from the command line |
